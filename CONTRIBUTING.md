# Contributing to CampusNotes

## Branches
- Create a new branch for every change: `feature/<your-name>-<change>`
- Never commit directly to main; all changes reach main only through a reviewed pull request

## Commit messages
- Use Conventional Commits: feat:, fix:, docs:, refactor:, chore:
- Example: `feat: add Unit 5 notes`
- Keep the first line short and clear

## Pull requests
- Explain what you changed and why
- Link the related issue (for example: `Closes #<issue-number>`)
